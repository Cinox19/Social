# GTA Timers public update channel

This branch only hosts the public APK update feed for the private GTA-Timers project.

- `gta-timers/latest.json` is read by the Android app.
- `gta-timers/latest.apk` is the latest signed APK.
- `gta-timers-publish/request.json` is updated by the project maintainer to publish a new build.

The application source remains in the private `Cinox19/GTA-Timers` repository.
